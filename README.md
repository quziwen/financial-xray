# 财报显微镜（financial-xray）

招股书/年报深度解读 AI 技能 —— 给定招股书、年报、业绩公告链接或公司名/股票代码，按 9 章骨架 + 19 条写作纪律 + 财报质量红旗校验 + 同业对标 + 强制交付门禁，产出可追溯、带判断、经质量校验的深度分析报告。

## 触发方式

- ① 甩招股书/年报链接 + 说"解读/分析一下"
- ② 给公司名或股票代码 + 说"分析一下"（自动定位官方文件）

## 版本

- **v2.0** (2026-09-05)：门禁内化 + 结论先行摘要 + 量化层 M-Score/Z-Score + 反差清单 + 准则自适应 + 同业对标
- v1.0 (2026-09-03)：9 章骨架 + 15 条纪律（从 SHEIN 报告逆向）
