# 可复用经验与视觉偏好累积（Learnings）

> 本文件沉淀实战中验证有效的经验与视觉偏好，供后续生成报告时查阅。普通分析任务不自动追加；只有用户明确确认「沉淀」时才修改。

---

## 视觉与版式偏好（2026-09-05，历史案例记录）

- **正文两端对齐**：中文正文必须 `text-align: justify`，否则右边参差不齐（Patrick 明确指出）
- **表格左对齐、数字右对齐**：表格内不 justify（避免拉大词距），金额/比率用 `.num` 右对齐 + tabular-nums
- **深蓝 hero 可保留但克制**：hero 用于大字数据，但不要过度压迫；正文用米白/浅灰底色 + 白色卡片，柔和舒适
- **四档摘要用语义色**：🟢绿（好的）/ 🟡黄（不足）/ 🔴红（红旗）/ ⛔深红（重大问题），一眼区分严重度
- **重点靠有限粗体 + 风险红**，不靠密集大段加粗
- 表格过宽时横向滚动（.tw overflow-x），不压缩字号到不可读

## 报告结构经验（2026-09-05 实战沉淀）

- **标题只体现分析主体**：财报模式 `{公司}({代码}){年度}年{报/中期业绩}深度解读`；招股书模式 `{公司}({代码})招股书深度解读`——不把招股书+年报+中报堆进标题
- **摘要聚焦分析主体**：四档分类只放"当前分析主体"的数据，对比基准（招股书/往年报）明确标注时点（如"2025FY 基准"、"2025 年报一次性"）
- **门禁/分析框架不进交付物**：门禁（Phase 0/5）、分析框架（四件套等）、bundle 都是 internal，报告只给读者结论和证据
- **历史数据进正文不进摘要**：如"超购 4,452 倍""毛利率 55.4%"这类上市/往年数据，放 01 一页看懂或 02 关键数据，不进核心结论速览

## 数据可得性经验（2026-09-05，历史案例记录）

- **港股 AI 同业数据源好**（范式智能/微盟：业绩公告 + 智通/格隆汇/澎湃多源），A 股同业（同花顺）年报摘要够用但毛利率/市值需原文
- **估值维度（市值/P/S）常缺失**：同业对标时市值优先"最新交易日 × 总股本"，总股本从年报/公告拿
- **披露易 API 失效时**：媒体多源交叉 + 原文 PDF，信源降二级并标注"待原文核验"
- **招股书聆讯/申请版常无精确财务**：需更多"待核"标注 + 明确二级信源降级

## 分析对象模式提醒（2026-09-05 招股书 vs 财报实战）

- **招股书分析**（拟上市/递表）：主体=招股书，比较其内部可得历史期间；不强制额外往期文件。只有单期时不作趋势结论
- **财报分析**（已上市）：主体=最新财报，招股书+往年报为跨期验证基准，核心风险是"经营错配"
- 两类模式下摘要、标题、门禁 G4 的处理不同，启动前先判定
